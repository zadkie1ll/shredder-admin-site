# Концепт личного кабинета для ПК (Monkey Island)

`cabinet-concept.html` — статичный дизайн-концепт десктопного личного кабинета
в визуальном мире island-лендинга (`engine/templates/index_vpn.html`).
Концепт утверждён и внедрён (2026-09-10): скин боевого кабинета живёт в
`engine/static/css/cabinet-desktop.css` (+ точечные desktop-only блоки в
`dashboard.html`: полоса истечения, футер). Область — **только ПК-версия** кабинета:
мобильный кабинет имеет собственную утверждённую систему
(`docs/mobile-cabinet/DESIGN.md`) и этим концептом не затрагивается.

## Синтетические данные

Все данные на странице — вымышленные (synthetic), только для демонстрации
дизайна: email `user@example.com`, срок «23 дня / до 3 октября 2026»,
устройства (iPhone 15 Pro, MacBook Pro 14", Keenetic Giga), ключ подписки
`7f3a91c2-…`, реферальная ссылка `/r/7K2M9X`, счётчики 4 / +28, цена 299 ₽,
история платежей (3 оплаты по 299 ₽), тексты FAQ.
QR-код — декоративная заглушка с финдер-паттернами, не сканируется.
Вкладка «Демо» (секция 06) — служебная для концепта: варианты карточки
доступа (истекает / не оплачен), полоса истечения (в бою — над навигацией
на всех вкладках при ≤ 3 днях, как ip-topbar лендинга) и email-вариант
баннера привязки. В реальный кабинет отдельной вкладкой не идёт.
При внедрении все значения берутся из реальных источников
(PostgreSQL + Remnawave через RWMS), как в текущем dashboard.html.

## Как посмотреть

```bash
python3 -m http.server 8765 --directory docs/cabinet-desktop
```

и открыть <http://localhost:8765/cabinet-concept.html>
(запись `cabinet-concept` есть и в `.claude/launch.json`).

## Дизайн-решения

- Мир «Продолжение лендинга»: sticky-навигация лендинга, карточка
  «Ваш доступ» вместо hero, номерные sec-num-плашки секций.
- По решению пользователя (2026-09-10) контент разбит на вкладки — пункты
  навигации переключают панели: Главная · Устройства · Установка ·
  Рефералы · Поддержка · Профиль (+ служебная «Демо»); hash в URL
  открывает нужную вкладку.
- Привязка аккаунтов: на Главной баннер «Привяжите Telegram — +7 дней»
  (когда `telegram_id` пуст; уведомления бота конвертятся в продажи);
  для пришедших из бота — email-вариант баннера (демо во вкладке «Демо»).
  Смена почты — строка «Почта → Сменить» в Профиле (боевой flow —
  существующий `update_email` с письмом-подтверждением).
- Истечение подписки продаёт явно: полоса над навигацией «Доступ истекает…
  Продлить за 299 ₽» (грамматика ip-topbar лендинга) + карточка состояния
  с ценой в кнопке.
- Профиль повторяет мобильный набор: Telegram-статус, почта, автоплатёж,
  история платежей (раскрывается, внизу тихая ссылка «Отключить
  автопродление»), FAQ, «Добавить на рабочий стол», соглашение, политика.
- Поддержка: Telegram + FAQ, статус-полоса «Все системы работают»;
  тикеты на сайте сознательно не создаются.
- Контракт направления: `.impeccable/surfaces/docs-cabinet-desktop-cabinet-concept-html.md`.
