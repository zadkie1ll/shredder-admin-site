## Изменение разметки

Единственная изменённая функция — `configTemplateCard(template)`. Значения `entry_name`, `dialer_proxy_name` (включая прежний fallback `ROUTING-IN`), `enable_dialer_proxy`, `profile_update_interval` перенесены из комбинированных плашек в `dl.config-template-facts`. Состояние шаблона и плашка наличия дополнительных заголовков сохранены, рядом показано число заголовков. Используется прежнее экранирование. Название, идентификаторы и действия редактирования/удаления сохранены.

## Сохранённое поведение

Стили не заменяют обработчики, API, данные, формы и поля. Сохраняются: выбор всех/части проверок ТСПУ; настройки ключей и массовых изменений; запуск и история замеров; создание установки и одноразовая команда; выбор и история версий скрипта; журнал установки; ограничения и фильтры трафика; персональные конфиги и User-Agent; проверки JSON; состояния и быстрые действия серверов; ручной лимит; диагностические графики, адреса и домены.

Оформление использует отдельные переменные для тёмной и светлой темы. Онлайн, ошибки, ограничение канала, архив, отсутствие данных и состояния операций продолжают определяться исходными классами. Столбец выбора ТСПУ шириной 64 px и мобильное выравнивание чекбоксов находятся в `admin-concept.css`; этот файл не переопределяет их.

## Проверка на локальных данных

Для проверки нужны реальные генераторы разметки с подставленными ответами API:

- ТСПУ: три проверки, ключ по умолчанию, успешный/частичный/пустой последний замер; `data-censor-select`, `data-censor-select-all`, `.censor-check-form`.
- Установка: активный скрипт с двумя версиями и длинным комментарием, черновик, заявка; `.node-provision-script-choice`, `.node-provision-code-stage`, `.node-provision-version-meta`.
- Конфиги: активный/неактивный шаблон, длинное имя, выключенный dialerProxy, заполненный/пустой `additional_headers`; `.config-template-facts`, `.config-delivery-card`, открытый редактор.
- Трафик: несколько пользователей, исключённая служебная подписка, долгий период; `.node-traffic-summary-grid`, `.node-traffic-row`, `.node-traffic-status`.
- Серверы: онлайн с определённым лимитом, онлайн с неизвестной скоростью, оффлайн, высокая загрузка, архив; `.infra-server-card`, `.infra-set-limit`, `.infra-server-card-meta`, карточка параметров.

Проверить оба оформления на 390, 760, 1024, 1440 px; форму конфигов также на 560/561 px. Источник функций — исходный код сайта. Команды установки, замеры, сообщения, изменения настроек и удаления при визуальной проверке не выполняются. Другие сервисы не затронуты: контракты, схема БД и бизнес-логика неизменны.
